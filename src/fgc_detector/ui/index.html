Applied to the running capture immediately; a changed host, port or password reconnects to OBS. The password is never sent back to this page — leave it blank to keep the stored one, or clear it.

Poll rate is the ceiling, not a guarantee. A winning marker can be on screen for under a second, so below ~2Hz a match end may never be confirmed; the log reports the rate actually achieved.

Detection tuning

Agreement frames is how many consecutive frames must read the same before an event fires — raise it against false positives, lower it if brief match ends are being missed. Editing any of these discards a part-built streak but leaves the detector armed.
